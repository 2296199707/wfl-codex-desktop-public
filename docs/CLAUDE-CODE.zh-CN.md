# Claude Code 管理员指南

WFL 固定并审查 Claude Code `2.1.236`。能力中心根据代码生成完整矩阵；候选版本如果
出现不同的 CLI 版本、构建提交、帮助语义、启动参数、命令或协议事件，会在激活前失败，
不会让未经审查的新协议直接进入正式运行时。

## 账号、供应商与暂停切换

- 每个用户最多保留十个 Claude 官方账号槽。登录失效时保留账号名称、邮箱、代理和历史
  绑定，并显示需要重新认证；彻底删除账号前会检查仍绑定的会话与暂停任务。
- API 供应商密钥和账号代理凭据按用户加密保存。连接检查只返回认证、额度、限流、网络、
  代理或服务端错误分类，不返回响应正文、密钥或原始诊断。
- 每个会话绑定自己的官方账号或 API 供应商。修改全局默认值不会热切换正在运行的会话。
  额度不足或账号失效时，先点“暂停”；按钮变为“继续”后，可切换账号或供应商，再从原生
  会话继续，网页不会重复增加用户消息。
- 无限重试默认关闭。开启后仍使用带抖动的递增退避和最大间隔；认证失败、额度耗尽、
  已观察到工具副作用的任务及投递状态未知的任务不会自动重放。

## 并发、断线与恢复

不同项目使用独立 Claude 子进程，可以同时运行三个以上项目。切换项目、刷新页面、关闭
前台或 WebSocket 暂时断线不会主动停止后台任务。浏览器重连后从服务端权威快照恢复耗时、
审批、输出和重试状态，并使用客户端消息 ID 防止重复发送。

服务重启或子进程异常退出后，WFL 会区分安全恢复、等待确认和未知投递。无法证明安全的
Turn 只显示“继续未完成任务”或“标记中断”，不会自动重跑可能有副作用的工具。Tool Result
按原生 Tool Use ID 绑定，缓存、实时流和 JSONL 记录按权威顺序合并。

## 权限

普通用户的 Claude 能力默认关闭，由所有者或管理员通过默认策略、套餐或单用户设置授权：

- Claude 运行时、官方登录、API 供应商
- Skills/Agents/Plugins、MCP、Hooks、Memory
- 后台 Agent、Worktree、账号代理
- 结构化输出、Ultra Review、工程清理、Anthropic Beta Header

服务端对每个 HTTP 和 WebSocket 操作重新鉴权。撤销运行或语义能力时，活动任务在当前安全
边界暂停，等待重试的任务立即进入持久暂停；不会停用账号或封锁对话。改变系统提示、
配置来源、MCP 白名单、插件、Hooks、Worktree、额外目录、结构化输出或 Beta Header 等
影响语义的设置，只对下一个新进程生效，不能在活动 Turn 中热切换。

执行参数中新增 Claude 2.1.236 的自动压缩窗口设置，可选择由 Claude 自动决定，或固定为
100K、200K、500K、1M tokens；留空时沿用 Claude 默认行为。服务端只接受 `auto` 或
100,000–1,000,000 tokens，恢复和分支会继承该设置。

## MCP、插件与后台 Agent

MCP 使用 Claude 原生 user/project/local 作用域，支持连接状态、工具与资源、OAuth logout、
项目批准/拒绝和重置项目选择。OAuth 地址只交给服务器隔离浏览器，浏览器端不接收真实
授权 URL。STDIO 环境变量、HTTP Header 和令牌只显示字段名与“已配置”。

本地插件必须位于获准工程边界内；URL 插件由服务器限制来源、大小和压缩包内容，校验后
物化为本地目录。Plugin 的更新、验证、清理、初始化、评估和标签操作均有独立的服务端
边界，高风险操作需要管理员授权。

原生后台 Agent 可按需继承当前会话草稿中的设置来源、MCP 白名单、本地插件、Hooks 和额外
目录。敏感 MCP/Hook 配置以 `0600` 临时文件交给 Claude，原生任务确认启动后立即删除；
任务中心只显示服务器名称、数量和启用状态，不显示配置内容、命令或对话正文。
