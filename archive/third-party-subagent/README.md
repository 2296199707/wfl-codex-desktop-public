# Archived third-party subagent integration

This directory contains the retired DeepSeek Harness / WFL third-party
subagent integration, its configuration, tests, probes, and historical
documentation.

It is retained for reference only. Nothing under this directory is part of
the active server, browser UI, provider store, package manifest, or release
archive. The supported collaboration path is the official Codex subagent
protocol.

The archived source was moved out of `lib/`, `scripts/`, `config/`, and
`test/` so it cannot be imported or discovered as an active implementation.
