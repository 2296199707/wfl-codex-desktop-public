# Changelog

All notable changes to WFL Codex Desktop are recorded here. Versions follow
[Semantic Versioning](https://semver.org/).

## [0.44.64] - 2026-08-29

- 服务器文件管理器下载支持标准 HTTP Range 断点续传，并通过文件校验标识避免续传不同版本的文件。
- 服务器文件管理器上传支持可恢复分块传输；单用户模式改为登录页登录，避免普通页面触发浏览器 Basic Auth 弹窗。

## [0.44.63-beta] - 2026-08-28

- 修复图片供应商工具对同步 `capabilities` 回调错误调用 `.catch()` 导致生成请求尚未发出就失败的问题。

## [0.44.62-beta] - 2026-08-28

- AI 供应商图片测试插件增加 managed、partial 和 passthrough 参数模式，支持供应商原生参数透传。
- 供应商返回图片尺寸与请求不一致时不再拒绝结果；普通生成、编辑保留实际尺寸，扩图会适配后继续合成。

## [0.44.61-beta] - 2026-08-28

- 收敛对话列表、历史恢复、Thread 状态和连接恢复的并发请求；同一对话的在途读取共享，迟到的旧任务事件不会重新打开或覆盖当前任务。
- 发送路径仅在已确认的未物化 Thread 上跳过重复快照读取，保留不确定投递的核验，降低正常发送和长任务切换期间的重复同步。

## [0.44.60-beta] - 2026-08-27

- 延长并允许配置蓝绿部署的后端认证交接等待时间，避免长任务或线程加载期间被 16 秒固定超时误判为发布失败。

## [0.44.59-beta] - 2026-08-27

- 修复多对话切换、长任务恢复和中断目标串线：恢复状态与请求按对话隔离，迟到响应不会覆盖当前对话，发送只等待目标对话恢复。
- 普通任务状态轮询不再隐式读取完整对话记录，降低长任务对历史加载和切换的阻塞。
- 增加线程并发恢复研究记录及关键回归测试。

## [0.44.56-beta] - 2026-08-27

- 将聊天记录列表、对话恢复和历史分页的客户端与服务端超时整体放大约 10 倍；列表支持先显示已加载内容，超时不会清空当前对话。

## [0.44.55] - 2026-08-25

- 修复服务器文件管理器点击目录名称无法进入下一级的问题；目录名称现在支持单击进入，其他列仍可用于选中操作。
- 将 WFL Codex Desktop 自有代码和 Windows companion 改为 MIT，并新增第三方许可清单；保留 Android SyncVault、网盘 APK、字体及运行时依赖的原许可证。

## [0.44.54-beta] - 2026-08-25

- 在 WFL 工具中心增加仅管理员可用的服务器全局文件管理器，支持目录浏览、文本编辑保存、创建、重命名、删除、上传和下载，并记录操作审计。

## [0.44.53-beta] - 2026-08-25

- AI 供应商真实测试插件现在暴露 Responses `context_management`、可选 `previous_response_id` 和 `store`；完整保留 SSE/非流式 compaction output item，支持 Agent 无状态续接和插件页 input item 回放。
- 扩大真实测试插件的请求/响应传输空间以承载约 20 MB 的加密 compaction 上下文，并增加 Fake Responses Provider 的 compaction round-trip 覆盖。

## [0.44.52-beta] - 2026-08-24

- 调整 AI 供应商真实测试参数：输出 Token 上限由调用者设置并直接传给供应商，不再使用固定的 4096 上限。
- Agent 测试页新增最大轮数和工具调用次数设置，并放宽提示词、Schema、工具结果和响应展示的过低限制；保留请求/响应大小、超时、虚拟工具和防无限循环边界。

## [0.44.51-beta] - 2026-08-24

- 完善 AI 供应商 Agent 测试插件：增加模型推理强度、保存配置和恢复配置能力，API Key 不写入浏览器保存内容。
- 明确最大输出 Token 是输出上限，并展示实际 Usage、完成状态、截断原因和不完整详情，单次请求、Agent、测试套件及 MCP Schema 保持一致。

## [0.44.50-beta] - 2026-08-24

- 修复 AI 供应商真实测试弹窗在手机端内容超出屏幕后无法滚动的问题，并适配动态视口和底部安全区。
- 明确说明单次请求、Agent 工具循环和固定测试套件的区别；页面同时展示 AI 会话可连续调用的全部供应商测试 MCP 能力。

## [0.44.49-beta] - 2026-08-24

- 在 WFL 插件页新增 AI 供应商 Agent 真实测试插件，复用已授权的供应商配置，支持 Responses 请求、流式响应、结构化输出、Function Tool Call、多轮 Agent 测试和有界测试套件。
- 新增 `ai_provider_list`、`ai_provider_models`、`ai_provider_test`、`ai_provider_request`、`ai_provider_agent_test` 和 `ai_provider_run_suite` MCP 工具，并提供本地 Fake Responses Provider 测试覆盖。
- 限制供应商、请求、响应、工具调用和测试轮数，统一脱敏 API Key，停用插件或撤销授权后立即失效。

## [0.44.48-beta] - 2026-08-23

- 移动 App 预览重建复用稳定的 Flutter Release 编译工作区和缓存，构建完成后再发布静态文件；实测同一工程热构建由约 62 秒降至约 8 秒。
- AI 移动预览新增点击、输入和滚动工具，并在同一用户浏览器会话中连续操作；新构建会自动刷新，停止预览或退出时会释放会话。

## [0.44.47-beta] - 2026-08-23

- 预览构建会同步完整 Flutter 工程及递归本地 `path:` 依赖，并自动清理过期构建目录和日志。

## [0.44.46-beta] - 2026-08-23

  browser API, leaving one authenticated **Sync update** path for application
  releases while retaining the internal checked release worker.
- Let **Sync update** revalidate and activate an already synchronized stable
  tag when a previous candidate switch failed after the source fast-forward,
  so removing the separate deployment action does not remove recovery.
- Added verified release-package installation with an external SHA-256 file,
  an internal version-to-commit manifest, safe archive-path checks, and an
  optional read-only Git remote bootstrap for future updates.
- Added a top-level `install.sh`, installation locking, free-space and source
  preflight checks, supported Node.js installation, stage-specific failure
  guidance, idempotent password preservation, and final deep service checks.
- Documented private-clone and downloaded-package setup separately, including
  offline limitations, per-server deploy keys, reruns, and Cloudflare cutover.

## [0.12.0] - 2026-07-20

- Added authenticated remote stable-version discovery and a durable safe-update
  worker for private Git repositories, using stable tags contained in
  `origin/main` instead of deploying an untagged branch head.
- Prepare each remote version in an isolated Git worktree, install its locked
  dependencies, and run the complete unit, integration, and Playwright suite
  before fast-forwarding the control checkout or starting blue-green deployment.
- Added a compact remote-version view and explicit sync confirmation to the
  version center, with bounded progress that never returns repository
  credentials, command output, provider keys, or conversation content.
- Drain releases safely by blocking new turns and waiting for the current task
  before starting the candidate backend; legacy servers require an explicit
  one-time idle confirmation instead of silently bypassing this check.
- Documented per-server read-only deploy keys, one-time bootstrap, routine UI
  and CLI updates, local-data boundaries, and failure recovery for additional
  private servers.
